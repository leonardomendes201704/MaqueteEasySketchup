# Backlog do PlanForge Builder

Este arquivo guarda a fila de evolucao do plugin e deve ser atualizado a cada release.

## Concluido

- [x] Estrutura base da extensao SketchUp com menu, toolbar, painel HtmlDialog e versionamento por releases.
- [x] Ferramenta de paredes com preview, snap configuravel, ortho mode, espessura, altura e alinhamento.
- [x] Piso 3D automatico ao fechar o comodo, com espessura configuravel.
- [x] Ajuste de cantos entre paredes com encontro em miter.
- [x] Piso encaixado pela face interna das paredes.
- [x] Corte de portas com ghost preview e confirmacao por clique.
- [x] Corte de janelas com ghost preview e snap magnetico do topo na altura das portas.
- [x] Rodape interno automatico e regeneracao manual.
- [x] Rodape apoiado sobre o piso quando o comodo possui piso.
- [x] Edicao parametrica de paredes, portas e janelas.
- [x] Regeneracao completa do comodo a partir da selecao.
- [x] Materiais automaticos por tipo de elemento.
- [x] Organizacao automatica em tags separadas para paredes, pisos e rodapes.
- [x] Geracao automatica de comodo retangular com modal de medidas e ghost de posicionamento.
- [x] Reconciliacao automatica de paredes compartilhadas entre comodos do plugin para evitar sobreposicao visual.

## Proximas iteracoes sugeridas

- [ ] Presets de ambientes e familias de paredes.
- [ ] Biblioteca reutilizavel de portas e janelas.
- [ ] Pavimentos / niveis.
- [ ] Medidas e area do comodo sempre visiveis.
- [ ] Handles visuais para editar paredes e aberturas direto no modelo.
- [ ] Geracao externa ou em ambos os lados para rodape.
- [ ] Migracao automatica de metadados entre versoes.
