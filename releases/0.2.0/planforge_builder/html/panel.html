Desenho rapido de paredes para maquetes

Ajuste snap, espessura, altura e alinhamento. Depois ative a ferramenta e desenhe como se estivesse montando comodos.

Fluxo rapido

  1. Ative a ferramenta.
  2. Clique para iniciar a primeira parede.
  3. Mova o mouse para definir direcao e comprimento.
  4. Clique de novo para criar a parede e continuar em sequencia.
  5. Pressione Enter para fechar o ambiente no ponto inicial.
  6. Ao fechar o contorno, o piso 3D e criado com a espessura configurada.

Dica: voce pode digitar um comprimento na caixa de medidas do SketchUp depois de mover o mouse.
